# La visite d'une liste neuve

Date : 23 novembre 2026. Demandé par Julien : « un petit tuto la première fois qu'on arrive sur cette liste, avec notre système d'overlay violet ».

## Ce qu'on a décidé

- La première fois que quelqu'un arrive sur une liste qu'il vient de créer, une visite passe d'élément en élément, avec le voile et la note de la première coche.
- **Elle est courte et se passe** : une phrase par étape, « Passer » toujours là, une seule fois par compte. Une visite qui explique tout, on la ferme sans lire.
- **Deux visites**, parce que les deux listes ne se ressemblent pas : depuis un Secret Santa, j'y suis déjà et quelqu'un lit ce que j'écris (six étapes) ; depuis « Créer », la liste est vide et personne ne la voit (trois étapes, puis une note quand la première personne est ajoutée).
- Elle remplace les phrases d'aide posées dans la page (« Touche un texte pour le modifier. »).

## Ce qu'on a écarté

- Une visite complète de tout ce qu'une liste sait faire (cocher pour quelqu'un, déplacer, les goûts…) : chacun de ces gestes s'apprend là où il se fait.
- La rejouer depuis un menu : rien ne le demande pour l'instant.
