# Les décisions

Un fichier par décision, daté, court. On n'y revient pas : si une décision change, on en écrit une nouvelle qui dit laquelle elle remplace, et on corrige la spec.

Une décision dit : **le contexte** (ce qui posait problème), **la décision**, **ce qui a été écarté et pourquoi**, **où elle s'applique** (les fichiers de la spec, les maquettes).

Ce qui était décidé avant le 20 novembre 2026 est dans le `README.md` de la racine (section 2 et les sections datées) et dans l'archive `docs/refonte/PLAN.md` (section 6, « Questions pour Julien », avec ses réponses).

Nom du fichier : `AAAA-MM-JJ-la-decision-en-quelques-mots.md`.
