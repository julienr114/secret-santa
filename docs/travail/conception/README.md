# Les tickets de conception

Ce dossier est à la conception (l'application Claude). **Claude Code n'a rien à y lire pour coder** : ce qui compte pour le code est dans `docs/spec/`, dans les maquettes et dans les tickets numérotés.

Un ticket de conception, c'est une chose à dessiner ou à écrire avant qu'un ticket de code soit prêt. Il porte un « D » et un numéro.

| Dossier | Ce que ça veut dire |
|---|---|
| `a-dessiner/` | Reste à dessiner. Le ticket dit pourquoi, quoi, et ce qui l'empêche d'avancer. |
| `dessine/` | Dessiné, publié sur le canevas, copié dans `docs/refonte/maquettes/`, reporté dans la spec et dans les tickets de code. |

Un ticket dessiné dit toujours deux choses : **ce qui a été décidé seul**, pour que Julien puisse dire non, et **ce qui a été contrôlé** (quelles maquettes ont été regardées en image).
